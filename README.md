# 🍔 Online Food Delivery Prediction

## 📌 Project Overview
This project predicts whether a customer is likely to order food online based on their personal and demographic details.

## 🛠️ Technologies Used
- Python
- Pandas
- Scikit-learn
- Joblib
- Streamlit

## 📊 Input Features
- Age
- Gender
- Occupation
- Monthly Income
- Family Size
- Feedback

## 🤖 Machine Learning
A Machine Learning classification model is used to predict the customer's online food ordering preference.

## 🌐 Streamlit Application
The project includes a Streamlit web application where users can enter customer details and get a prediction.

The application displays:
- 🍔 Likely to order online food
- ❌ Unlikely to order online food

## 📁 Project Files
- `Online Food Delivery Prediction.ipynb` – Model development and analysis
- `app.py` – Streamlit application
- `Online_Food_Delivery_model.pkt` – Trained ML model
- `x_columns.pkt` – Model input columns

## 🚀 How to Run

```bash
pip install pandas scikit-learn streamlit joblib
```

Run the Streamlit application:

```bash
streamlit run app.py
```
